Thread 状态表

一个 thread = 文档里一个锚点。界面上用户只看到「评论」：一条评论 = 一条 ping，Agent 的一条回复 = 一条 pong。评论逐条发送，发出即成为 ping；ping 序列只由人追加，pong 序列只由 Agent 追加，一条 pong 累计确认到某个 ping 水位 —— 这就是「n 条 ping + 一条 pong」。 open := latestPingSequence > acknowledgedPingSequence —— 没有「解决」按钮，状态是算出来的。
