# UniDocs 运营后台 WebUI v0

实现更新：[Iteration 14](iteration-14.md) 已上线真实目录和审计，沿用该视觉方案。按后续用户决定，enabled 仅为目标配置，页面明示“尚未接入主站”；无 editor 可保存目标启用，不显示主站已生效。主站消费和实际创建/编辑控制另行推进。审计首版仅最近 100 条，不提供全量翻页；操作只在页面内存恢复，不承诺跨刷新。

日期：2026-09-08。状态：按最新产品边界简化的交互设计；配套 [管理 API](unidocs-admin-api-v0.md) 和 [HTML 原型](unidocs-admin-mock.html)。此文取代此前分别管理服务、编辑器和发布版本的方案。

## 1. 界面边界

后台只有三项导航：文档类型、管理员、审计。类型列表即首页，不增加总览 dashboard。只注册一方服务；每种类型给一个 base URL，服务 API 与 editor 相对此 URL 解析。平台只控制主站创建/编辑入口是否开放，不管理版本、发布、回滚或微服务部署。

保留 [创作者原型](unidocs-mock.html) 的字体、logo、浅灰绿侧栏、白色工作区、黑色主按钮和细分隔线。页面是紧凑表格与无框详情区，表单使用简单弹窗，不使用多步骤发布向导。

管理后台复用 UniDocs 同一个 Google 登录，首版同源 `/admin/`。已有可信 Google 登录身份可直接进行管理员邮箱名单校验，不另注册 Google client/callback。非名单显示无权限，可换账号/退出；不提供首个登录自动成为管理员。管理会话与权限独立，退出管理不清普通工作台草稿。HTML 中的账号与登录都是模拟，不接 Google。

## 2. 页面与信息结构

| 页面 | 主要信息 | 操作 |
| --- | --- | --- |
| 文档类型 /types | 名称/ID、Base URL、主站状态、最近验证时间 | 搜索、状态筛选、登记、详情 |
| 类型详情 /types/:docType | 接入配置、变更记录两个 tab；发现名称/格式、派生 API/editor URL；已有作品数量 | 启用/停用、更换 URL |
| 管理员 /administrators | 邮箱、Google 身份绑定状态、添加人/时间 | 添加、删除别人；本人不可删 |
| 审计 /audit | 时间、操作者、动作、目标、结果 | 搜索、只读事件详情 |

不显示 Service ID 选择器、Editor Build 选择器、release、发布草稿、激活、部署或版本回退按钮。协议/能力是只读发现结果，不由运营编辑。主站状态与健康不是同一概念：已启用不等于实时健康，最近验证时间不能当持续监控。

```text
UniDocs           文档类型                         [+ 登记类型]
运营工作空间      [搜索名称、ID 或 URL] [所有状态 v]

文档类型          类型          Base URL                主站状态  最近验证
管理员            Markdown      https://markdown.../    已启用    今天 10:32
审计              PSD           https://psd.../         已启用    今天 10:28
                  Word 文档     https://docx.../        已停用    昨天 17:40

本人邮箱
[退出]
```

URL 全文可换行，复制可在后续实装提供；主页面不直接打开服务 API 或在管理 origin 加载 editor。未知依赖显示未核实，不伪造零件作品。

## 3. 登记类型

1. 点击“登记类型”，弹窗只有 Base URL 输入及“验证 URL”按钮。名称、类型 ID、API/editor 地址自动发现，不要求手填。
2. 验证中保留输入，禁止重复在途验证。结果展示类型身份、标准入口及错误项；失败不添加注册。
3. 通过后展示发现摘要与“在主站启用（可创建、编辑）”复选框，默认不勾选。点击“登记类型”才保存，取消没有生效配置变更。
4. URL 输入任何修改立刻清除通过状态，登记按钮禁用。重复类型在验证和提交时均检查，不能偷偷替换已有 URL。

生产 URL 安全验证在服务端执行，不因浏览器校验通过就跳过。HTML 原型仅匹配固定沙盒地址，不发起任何外部发现请求。

## 4. 更换 URL

从类型详情打开弹窗，带入当前 URL。输入新地址后必须重新验证，结果与该输入和当前配置 ETag 绑定。若类型身份、服务身份或存储连续性不匹配则拒绝，当前 URL 不变；未知和不可达也不能保存。

通过后填写变更原因，按钮“保存 URL”。确认文案指出此操作影响后续该类型访问，不执行迁移。改输入、验证过期或并发改配置时必须重新验证，不复用旧通过结果。

不显示“发布”“激活版本”“自动迁移”。同 URL 下微服务升级由微服务自己管理；新会话重新握手选择其提供的兼容行为，后台不选择 build。

## 5. 主站启用开关

启用：验证当前 URL，通过后明确确认，主站显示创建/编辑入口；实际操作仍受服务能力和用户权限约束。配置 enabled=true 不等于 receipt 或编辑器兼容已经实现。

停用：确认弹窗说明同时关闭创建与编辑，输入原因。已有作品不删除，读取/导出权限保留；在途原意图可以继续核实，不自动丢弃草稿。该读取语义为设计建议，若用户要求全面封禁需另行明确。

停用无需成功健康验证。服务出故障时运维仍能停止新写入口。按钮只提交该开关，不连带停 Worker、删除 URL 或撤销用户账号。

## 6. 管理员与审计

Google 管理员邮箱名单保持原约定：添加只有邮箱输入；规范化重复提示，不能索取密码/token。本人行显示“你”，删除禁用；服务端仍需原子资格/人数检查，不能用按钮代替安全控制。

删除别人要求明确确认，撤销管理资格不影响普通账号及文档权限。删除完成后旧管理会话失效；重新添加同邮箱也不能复活旧会话。

审计记录登记、验证通过/失败、更换 URL、启用/停用、管理员增删。展示脱敏字段和请求 ID；验证失败不能标成功。正文、cookie、token 和秘密 URL 不进入审计页面。

## 7. API 映射与失败处理

| UI 动作 | API |
| --- | --- |
| 目录/详情 | GET /document-types、GET /document-types/{docType} |
| 验证 URL | POST /url-validations，然后 GET /url-validations/{validationId} |
| 确认登记 | POST /document-types，body 为 baseUrl/enabled/validationId |
| 更换 URL | PATCH /document-types/{docType}，body 为 baseUrl/validationId/reason |
| 启用 | 同一 PATCH，body 为 enabled=true/validationId/reason |
| 停用 | 同一 PATCH，body 为 enabled=false/reason |
| 管理员 | GET/POST /administrators、DELETE /administrators/{adminId} |
| 审计/核实 | GET /audit-events、GET /changes/{idempotencyKey} |

所有业务路径相对 `/admin/api/v1`；名单与会话沿用 API 文档。PATCH 需 If-Match，ETag 仅防并发，不做 UI 版本管理。

401/403 清业务缓存并返回登录/无权限页面；412 保留内存输入，展示最新配置，不自动用新 ETag 重发；422 定位字段；503/断网在途写显示“结果待确认”，用原 key 核实，不假装失败就未生效。离开表单需确认，首版不承诺跨刷新恢复表单。

## 8. HTML 演示与验证范围

[原型](unidocs-admin-mock.html) 复用原样式，页面内存样例，刷新恢复初始值，不读写现有创作者原型存储。Google 登录、URL 发现、身份/存储检查均为演示；不能据其通过宣称真实服务已安全接入。

可演示 URL：

- `https://types.example.com/diagram/`：新类型登记，验证派生路径保留目录前缀。
- `https://markdown-next.example.com/`：Markdown 同身份 URL 切换。
- `https://psd.example.com/`：对 Markdown 验证时拒绝类型不匹配。
- `https://markdown-other.example.com/`：拒绝不同服务/存储身份。
- 其他地址没有沙盒发现数据，验证失败而非猜测类型。取消后不更改目录。

桌面 1440px 与平板 820px 检查表格、长 URL、弹窗和导航，平板菜单打开右侧抽屉；<=760px 保留电脑/平板提示。真实后台实装还需焦点、离开保护、异常/并发与权限测试。

验收：导航仅三项；无版本/发布/服务/编辑器独立管理；URL 校验前保存禁用；输入变化与取消不应用配置；错误身份不切换；成功更换保留类型身份与 enabled；停用关闭创建和编辑；管理员自删保护仍有效。
