## 已确定的产品约定

- UniDocs 是人和外部 Agent 共同创作、迭代数字作品的平台。
- Session 是长期存在的作品身份。主动 fork 才会产生独立作品。
- 正式 MVP 最初以 Markdown 收敛；本轮 mock 增加 PSD 最小编辑和跨类型引用，以验证统一框架，不代表纳入完整 PSD 编辑器。
- 「我的作品」只是导航入口，不是作品集。作品独立存在，以检索和版本引用建立联系，不要求树形目录或手工分组；tag 是可选检索线索。
- 工作台平铺作品，不按待审阅等业务状态划分作品。批注仍保留自身的解决状态。
- 搜索、类型和 tag 过滤器并列放置，可以组合使用。
- 创建使用统一的「新建作品」入口，再选择类型。当前 mock 提供 Markdown 和 PSD；最近或常用类型可另设快捷入口。
- 打开作品默认预览；选择 Markdown 类型后立即生成空白作品并进入源码、预览双栏。
- MVP 优先电脑和平板；手机先显示「请在电脑或平板上查看」提示页。
- 人可以编辑 Markdown；人和 Agent 写入均采用乐观锁，冲突时拒绝后提交者并保留草稿。
- 引用固定到 session 的明确版本。正文提供摘要，悬停预览显示该版本的标题和前若干字。源作品更新时提示，由人主动切换。
- 批注锚定特定版本。先积累私有草稿，再集中提交一轮反馈。
- 每条批注支持人和 Agent 回复，有解决状态，可过滤已解决线程。
- 单条批注、一轮反馈和作品均可通过链接定位，交接给外部 Agent。
- MVP 不做对外分享。用户或持有用户 JWT 的 Agent 才能访问；定位链接不携带 JWT、不授予权限。

## 本轮交互选择

这些是供体验和讨论的默认方案，不是额外确认的需求：

- 低饱和灰白工作空间，作品内容缩略图为主要视觉元素。
- 网格和紧凑列表两种视图；关键词匹配标题、正文和 tag。
- 桌面审阅面板默认打开，编辑时收起。已有手机响应式样式保留供后续继续设计，当前通过宽度不超过 760px 的提示页暂时遮蔽应用。
- Markdown 批注采用选中文字或整篇批注，暂未加入自由画笔。
- 一轮反馈可包含不同版本的批注；每条独立记录原版本，不强制整轮冻结。
- 正文摘要取引用版本前 64 字，悬停预览取前 120 字；触屏点击打开该版本。
- 引用更新写入本地编辑草稿，显式保存后生效。
- 解决操作暂由人主动确认；Agent 模拟只回复、不自动解决。
- 用户可从更多菜单更改标题、tag 或 fork 当前版本。
- 冲突不自动合并，可复制基础版本、最新版本与草稿的完整上下文交给 Agent。
- PSD 使用画布和图层属性，不套用 Markdown 双栏。新建 PSD 使用 1200 × 800 封面模板；支持文本、位置、字号和图层显隐的最小编辑。
- PSD 预览提供可折叠的分图层面板：缩略图、逐层显隐、单层查看和恢复原始显示。它们只改变临时查看状态，不写入草稿、不产生版本；导出和引用始终使用保存的版本。
- PSD 区域批注锚定画布坐标和版本，并记录当时的可见图层。通过该批注的定位链接可回看原版本和图层上下文。
- Markdown 可以插入 PSD 的固定版本渲染图，查看悬停预览、回到源作品，以及比较新旧版本后更新引用。

## 建议体验路径

1. 在工作台组合使用关键词、类型和 tag 筛选，打开「UniDocs · 产品构想」。
2. 选中正文，点击就地「添加批注」，积累几条，再提交反馈并复制本轮链接。
3. 在右侧线程回复、标记解决，切换「全部」查看已解决批注。
4. 悬停「版本引用约定」：当前引用 v2，但已有 v3。选择更新到草稿，再保存。
5. 进入双栏编辑，在光标位置引用另一篇 Markdown。
6. 编辑未保存时，从更多菜单点击「模拟 Agent 更新」，再保存，查看冲突和保留的草稿。
7. 回到工作台点击「新建作品」，选择 Markdown；也可从作品更多菜单 fork。
8. 打开「共创空间 · 封面设计」，切换分图层预览，框选区域添加批注；进入编辑后改字、调整位置或隐藏图层，再保存。
9. 打开「共创空间 · 发布手记」，其中引用封面 v1，而封面已有 v2。比较两版画面，再将新引用写入草稿并保存。
10. 在 Markdown 编辑中点击「引用作品」并选择 PSD，插入固定版本图片；在 PSD 未保存草稿上模拟 Agent 更新，验证乐观锁。

## 原型边界

- 所有作品、历史版本、批注与草稿都保存在当前浏览器的 localStorage 中，不连接生产服务。
- PSD 使用 Canvas2D 渲染 JSON 图层快照，不读取或写入真实 PSD 二进制，不接入现有 PSD 服务。可下载 PNG 预览；冲突草稿导出为 `.mock.json`。暂不支持上传、复杂绘制、图层特效或完整格式兼容。
- 新版本 mock 会为已有本地数据追加两件跨类型样例，不清除原作品或草稿。
- JWT 校验、API/MCP、真实 Agent 运行、实时推送、服务端私有草稿隔离尚未接入。页面里的身份和 Agent 更新是样例模拟，不能作为安全实现。
- 本地链接只对同一浏览器数据集有效，不应交给真实 Agent 当作可访问的服务链接。
- 乐观锁、版本引用与更新、评论状态在浏览器数据上真实执行，但不代表已验证后端并发协议。
- 初次加载需要联网获取固定版本的 Marked、DOMPurify、Lucide，以及字体和一张 Unsplash 样例照片。Markdown 使用 Marked 解析并经 DOMPurify 清理。
- 原型未接入认证，不用于真实敏感内容。清除此页面的浏览器站点存储会恢复初始样例，也会删除本地草稿。

- 桌面和平板视口检查：内容、筛选栏、编辑器、类型选择弹窗及横向溢出；手机视口检查提示页。
